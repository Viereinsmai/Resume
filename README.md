# Personal Portfolio

> A minimalist, bilingual (EN/CN) personal portfolio website showcasing academic background, work experience, research projects, teaching demos, and a photo gallery.

🔗 **Live Demo**: [https://viereinsmai.github.io/Viereinsmai/](https://viereinsmai.github.io/Viereinsmai/)

---

## ✨ Features

- **Bilingual Support** – Switch between English and Chinese with one click
- **Responsive Design** – Optimized for desktop, tablet, and mobile devices
- **Interactive Cards** – Click on education, experience, and project cards to view detailed descriptions with images
- **Horizontal Scrolling Gallery** – Browse photos with mouse or touch
- **Teaching Demos** – Showcase video recordings and downloadable PDF materials
- **Morandi Color Palette** – Soft, professional, and easy on the eyes
- **Built with Pure HTML/CSS/JS** – No frameworks or external dependencies (except Font Awesome icons)

## 🚀 Getting Started

### Local Preview
1. Clone or download this repository.
2. Open `index.html` directly in your browser.
3. No build tools or server required.

### Customization
- **Edit content**: Modify the text inside `index.html` (search for `data-i18n` or `entryDetails` in the JavaScript section).
- **Replace images**: Add your own images to the `images/` folder and update the `src` paths in the HTML.
- **Add teaching demos**: Edit the `teachingData` array in the JavaScript section.
- **Change colors**: Adjust the CSS variables in the `:root` selector at the top of the `<style>` block.

## 🌐 Deployment

This site is designed to be deployed on **GitHub Pages**.

1. Create a repository named `YourUsername.github.io` (or any name).
2. Push the code to the repository.
3. Go to **Settings → Pages** and select the `main` branch as the source.
4. Your site will be live at `https://yourusername.github.io/` (or `https://yourusername.github.io/repo-name/`).
